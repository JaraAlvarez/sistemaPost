# ADR-0002 · .NET 10 LTS como plataforma

- **Estado:** Aceptada · 2026-09-28 (aprobada por el propietario del producto)

## Contexto
Se evaluaron .NET, Node.js/TypeScript, PHP y Python (doc 03). Requisitos decisivos: servicio de Windows nativo, aritmética decimal exacta, periféricos (serial, USB, spooler), protección del código frente a la evasión de la licencia y distribución sin dependencias.

## Decisión
- **.NET 10 LTS** (C#) para el servidor de tienda, el agente de caja, el actualizador y el servidor de licencias.
- ASP.NET Core Minimal APIs; ejecución dual consola / Servicio de Windows (`AddWindowsService`).
- SDK fijado en `global.json` (10.0.401, `rollForward: latestPatch`).
- Publicación **autocontenida** `win-x64`: el cliente no instala .NET.

## Consecuencias
- ✅ `decimal` nativo, tipado fuerte, excelente integración con Windows y soporte LTS hasta noviembre de 2028.
- ⚠️ La publicación autocontenida pesa ~109 MB. Se optimizará (recorte, ReadyToRun, compresión) en la Fase 13.
- ⚠️ Antes de noviembre de 2028 habrá que migrar a la siguiente LTS (.NET 12).
